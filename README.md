# Reactor Studio

A Vegas-style video editor for YouTube videos, Shorts, podcasts and react videos, packaged as a Mac app.

**Get the app:** open the **Releases** section on the right and download the .dmg for your Mac.

Every change pushed to `main` is built automatically on a Mac by GitHub Actions and published as a new release.
The editor itself is `app/index.html`; `main.js` is the Mac app shell.
